# Cynaris W1D1 — CIA Interactions

## Interaction 1: Common SQL Pitfalls for Junior Analysts

**Question:** What are the most common SQL mistakes junior data analysts make when using SELECT, WHERE, AND, OR, NOT, LIKE, IN, BETWEEN, and IS NULL?

**Key learnings:**
- Select only the columns needed instead of always using SELECT *.
- Use parentheses when combining AND and OR.
- Use IN for matching multiple values.
- Use LIKE with % wildcards for pattern matching.
- BETWEEN includes both boundary values.
- Use IS NULL and IS NOT NULL to check missing values.
- Validate query results using sample data.

## Interaction 2: SQL Skill Boost and Career Guidance

**Question:** I am a beginner Data Analyst Intern learning SQL fundamentals. Give me a practice plan, suggest three sales-data projects, and explain how to demonstrate SQL skills on GitHub and in interviews.

**Key learnings:**
- Practise SQL filtering, logical operators, and pattern matching regularly.
