# W5D5 - AI-Powered EDA on Indian Business Dataset

## Project Overview
This project analyses an Indian retail sales dataset containing 100,000 records and 25 columns.

## Tools Used
- Python
- Pandas
- Matplotlib
- Sweetviz

## Project Structure
- data/ - Dataset
- scripts/ - EDA and validation scripts
- charts/ - Visualisations
- reports/ - Analysis reports
- evidence/ - Business insights and data quality

## Key Findings
- Total sales: INR 2,508,441,014.18
- Total profit: INR 375,530,511.43
- East region recorded the highest sales and profit.
- Sessional Fruits & Vegetables had the highest category sales.
- Household Items had the highest category profit.

## Data Quality
- 100,000 rows and 25 columns.
- No missing values or duplicate rows.
- All records are from India.

## Limitations
Date columns contain inconsistencies, so monthly and yearly trends may be unreliable. Every Customer ID is unique, and all recorded profits are positive.

## How to Run
python week-05/day-05/scripts/run_eda.py
python week-05/day-05/scripts/validate_project.py

## AI Usage
ChatGPT helped interpret results and develop recommendations. Python and Pandas performed the calculations. No external LLM API was connected.
